Brightness-based auto-filter/auto-wha effect.

VST3 audio plugin implementing an auto-wah effect based on audio signa lbrightness. The band-pass filter moves automatically according to the spectral content, modulating the centre frequency based on the ratio between high and low components, creating a real-time auto-wah effect.
